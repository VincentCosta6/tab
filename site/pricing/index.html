How do I start the trial?

Download tab, open Settings → Hub, sign in with Apple or Google, and choose tab cloud. Setting up your private hub starts the 14-day trial.

What happens when the trial ends?

Choose a plan to keep using tab cloud. Your data stays in your hub, and you can import it back to a local hub any time.

Do I need an Anthropic API key?

No. Agents use your existing Claude Code, Codex, OpenCode or Pi login. An API key is only needed for the optional Haiku ranking layer.

Is tab open source?

tab's source is on GitHub under the Functional Source License, which converts to MIT.
