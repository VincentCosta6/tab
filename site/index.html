How it works

Stop checking six apps to find out what's on fire.

tab is a modular work queue for engineers, designers and PMs. It does the triage so you can do the work.

1

Connect

Connections bring in everything that needs you: review requests, failing builds, mentions, email, meeting follow-ups and agents waiting on you.

2

Rank

A deterministic score you can read, refined by your own instructions through Claude Haiku. Urgent work floats up, noise sinks.

3

Annihilate

Open any item and work it with an agent that already has the context. Approve its steps, mark it done, move to the next.

Features

A queue that does more than list things.

💬

An agent on every item

Claude Code, Codex, OpenCode or Pi, with your own login. Each item gets its own session that picks up where you left off.

🧭

Context that finds itself

The ticket, the PR, the thread: agents attach what's part of the work and file what might matter under Found.

🔍

Built-in code review

A side-by-side diff with line comments that post straight to the PR. No tab switching.

⚖️

Rate budgets

Every connection respects its provider's limits. Interactive work stays fast; background refreshes wait their turn.

🗂️

Projects that remember

Repos, rules and notes per project, so the next chat starts knowing how your team works.

⏰

Tasks and schedules

Create tasks with priority and due times, or let agents create follow-ups for you.
