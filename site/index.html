How it works

Stop checking six apps to find out what's on fire.

tab is a work queue for engineers, designers and PMs. It does the triage, so you can do the work.

1

Connect

Connections bring in review requests, failing builds, mentions, email, meeting follow-ups and agents that are blocked on you.

2

Rank

A score you can read, refined by your own instructions through Claude Haiku. What's urgent rises to the top. Noise sinks.

3

Annihilate

Open any item and work it with an agent that already has the context. Approve its steps, mark it done, and move to the next one.

An agent on every item

Watch it work. Steer it mid-turn.

Each item gets its own agent session that picks up where you left off. You see what it's doing, what it knows, and what it costs.

  • Its plan, live. Steps tick off while the agent works, with the command it's running right now.
  • Rich links. PRs it mentions show their title, state and checks right in the reply.
  • Context and cache. See how full the context window is, and how long the prompt cache stays warm.
  • Context that finds itself. Agents attach the ticket, PR or thread they're working from, and file what might matter under Found.
